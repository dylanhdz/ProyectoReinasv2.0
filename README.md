# ProyectoReinas

## Para funcionamiento local
1. El archivo ip en /src/pages/ip.js debe modificarse por: https://localhost:3000;

## Para funcionamiento en red

1. Se debe modificar el package.json del client para incluir la ip de la red en ese momento usando '--host:192.168.0.0', donde 192.168.0.0 es la ruta.
2. Se debe modificar la ip de base en el componente de la ip, localizado en el /src/pages/ip.js
